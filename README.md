# DES Studio Telegram Bot

Публичная версия: `PsychoCatZ/DES-Studio-Bot-public`. Лицензия — [MIT](LICENSE).
Здесь исходники, тесты и демонстрационные данные. История private-репозитория,
рабочие заявки, секреты и настройки действующего сервера не включены.
Цены в каталоге — пример наполнения, а не актуальное предложение.

Автономная Telegram-витрина услуг DES Studio. Бот показывает data-driven каталог и цены, открывает карточки портфолио, принимает пошаговые заявки, сохраняет их в SQLite и отправляет владельцу. AI-модели и внешние AI API в этой версии не используются.

## Возможности

- 7 направлений и 38 услуг из `data/catalog.json`;
- компактный прайс по категориям;
- портфолио из `data/portfolio.json`, включая необязательные изображения и ссылки;
- заявка из главного меню или из карточки конкретной услуги;
- необязательные срок, бюджет и комментарий;
- подтверждение, перезапуск и отмена заявки;
- автоматическое получение Telegram ID, username, имени и фамилии пользователя;
- сохранение заявок в SQLite и уведомление владельца;
- постоянный учёт источника клиента через deep link или необязательный вопрос;
- единый HTML-режим с экранированием пользовательского текста;
- нейтральное сообщение пользователю и запись в лог при внутренней ошибке.

## Требования

- Python 3.12 или новее;
- Telegram-бот, созданный через BotFather;
- доступ к Telegram Bot API во время работы.

## Установка

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Для Linux/macOS команда активации: `source .venv/bin/activate`.

## Настройка `.env`

Скопируйте `.env.example` в `.env`:

```powershell
Copy-Item .env.example .env
```

Заполните значения:

```dotenv
BOT_TOKEN=123456789:your_bot_token
ADMIN_CHAT_ID=123456789
APP_TIMEZONE=Asia/Krasnoyarsk
DATABASE_PATH=data/orders.db
```

`.env` уже добавлен в `.gitignore`; не публикуйте токен и не добавляйте этот файл в Git.

### Где взять BOT_TOKEN

1. Откройте официальный аккаунт `@BotFather` в Telegram.
2. Выполните команду `/newbot`.
3. Задайте имя и username бота.
4. Скопируйте выданный токен в `BOT_TOKEN`.

### Как задать ADMIN_CHAT_ID

`ADMIN_CHAT_ID` — числовой Telegram ID владельца или чата, куда должны приходить заявки. Узнать личный ID можно через специализированного Telegram-бота для показа ID. Если заявки отправляются в группу, добавьте созданного бота в группу и укажите ID этой группы; у групп ID обычно отрицательный.

До приёма первой заявки владелец должен открыть созданного бота и нажать Start. Telegram не позволяет боту первым начинать личный диалог с пользователем.

## Проверка и запуск

Проверить импорты, JSON, маршруты и создание SQLite без подключения к Telegram:

```powershell
python bot.py --check
```

Запустить бота:

```powershell
python bot.py
```

Запустить автоматические проверки:

```powershell
python -m unittest discover -s tests -v
```

## Развёртывание на VPS

Рабочая SQLite-база и `.env` намеренно не хранятся в Git. При первом запуске бот создаст новую базу по пути из `DATABASE_PATH`; для переноса существующих заявок скопируйте `data/orders.db` на сервер отдельно безопасным способом.

Это пример новой установки под отдельным пользователем `studio-bot`.
Заранее создайте пользователя и доступный ему каталог `/srv/studio-bot`.
Эти пути не описывают действующий сервер DES Studio.

```bash
cd /srv/studio-bot
git clone https://github.com/PsychoCatZ/DES-Studio-Bot-public.git app
cd app
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
nano .env
.venv/bin/python bot.py --check
```

Пример `/etc/systemd/system/des-studio-bot.service`:

```ini
[Unit]
Description=DES Studio Telegram Bot
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=studio-bot
Group=studio-bot
WorkingDirectory=/srv/studio-bot/app
ExecStart=/srv/studio-bot/app/.venv/bin/python /srv/studio-bot/app/bot.py
Restart=always
RestartSec=5
Environment=PYTHONUNBUFFERED=1

[Install]
WantedBy=multi-user.target
```

После создания файла:

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now des-studio-bot
sudo systemctl status des-studio-bot
```

Не запускайте одновременно локальный и серверный polling с одним `BOT_TOKEN`: Telegram должен получать обновления только одним экземпляром бота.

## Управление каталогом

Каталог полностью хранится в [`data/catalog.json`](data/catalog.json). После изменения файла перезапустите бота.

### Как добавить услугу

Добавьте объект в массив `services`:

```json
{
  "id": "unique-service-id",
  "category_id": "web",
  "title": "Название услуги",
  "short_description": "Короткое и понятное клиенту описание.",
  "price_from": 3000,
  "price_to": 10000,
  "price_text": "3 000–10 000 ₽",
  "active": true,
  "sort_order": 70
}
```

- `id` должен быть уникальным;
- `category_id` должен совпадать с ID существующей категории;
- `active: false` скрывает запись;
- `sort_order` задаёт порядок;
- `price_text` используется для отображения цены;
- дополнительно поддерживаются `full_description`, `features` и `portfolio_ids`.

Обработчики Python и клавиатуры менять не нужно: услуга автоматически появится в своей категории.

## Персональные реферальные ссылки

Любой пользователь может один раз создать постоянный технический код кнопкой «🔗 Получить реферальную ссылку» в главном меню или альтернативной командой:

```text
/ref
```

Бот возвращает нейтральную персональную ссылку:

```text
https://t.me/your_bot_username?start=ref_ab12cd34
```

Кнопка и команда используют одну бизнес-логику. При повторном нажатии или повторном `/ref` пользователь получает ту же ссылку. Код связан со стабильным Telegram user ID и не меняется вместе с username.

При первом открытии валидной ссылки клиент постоянно привязывается к владельцу кода. Self-referral запрещён, а следующая ссылка не перезаписывает первую атрибуцию. Обычный `/start`, закрытие Telegram, новая заявка и перезапуск приложения привязку не удаляют.

Если автоматической привязки нет, заявка необязательно спрашивает, кто порекомендовал DES Studio. Ручной ответ запоминается после отправки; вопрос можно пропустить.

## Ответ клиенту через бота

Уведомление администратора содержит номер заявки и кнопку «💬 Ответить клиенту». После нажатия бот создаёт отдельное служебное сообщение с `ForceReply`, поэтому Telegram сразу открывает поле ответа, связанное с этой заявкой.

Связь служебного сообщения с заявкой хранится в SQLite, поэтому можно одновременно готовить ответы нескольким клиентам. Username клиента не требуется: доставка выполняется по сохранённому Telegram chat ID. Если клиент заблокировал бота, администратор получает понятное сообщение об ошибке. Обычное сообщение администратора без Reply не теряется молча: бот объясняет, как выбрать нужную заявку.

До первого успешно доставленного ответа DES Studio переписка по заявке закрыта: произвольные сообщения клиента не пересылаются администратору. После успешной доставки канал открывается только для конкретной заявки, а под ответом появляется кнопка «💬 Ответить по заявке #N» с `ForceReply`.

Клиент может ответить кнопкой, обычным Telegram Reply или простым сообщением. Простое сообщение автоматически относится к заявке, если открыта ровно одна переписка. Если открытых заявок несколько, бот показывает выбор и не угадывает. Текст, фотографии, документы и подписи к ним пересылаются без скачивания файлов. Администратор может отвечать Telegram Reply непосредственно на сообщение клиента; вся цепочка продолжает маршрутизироваться по `order_id`.

### Как изменить цену

Найдите услугу по `id` и измените `price_from`, `price_to` и `price_text`. Для услуги без фиксированного диапазона можно использовать `null` в числовых полях и понятную формулировку в `price_text`.

### Как добавить категорию

Добавьте объект в массив `categories`, затем используйте его `id` в услугах. Новая активная категория автоматически появится в главном меню, прайсе и выборе направления заявки.

## Управление портфолио

Проекты хранятся в [`data/portfolio.json`](data/portfolio.json). Для нового проекта добавьте объект:

```json
{
  "id": "project-id",
  "title": "Название проекта",
  "short_description": "Краткое описание проекта.",
  "image": null,
  "url": null,
  "active": true,
  "sort_order": 60
}
```

`image` и `url` необязательны. `image` может содержать HTTPS-ссылку или путь к локальному файлу относительно корня проекта. Не добавляйте фиктивные ссылки: текстовая карточка работает самостоятельно.

## База заявок

По умолчанию база находится в `data/orders.db`. Путь можно изменить через `DATABASE_PATH`. Таблицы создаются автоматически:

- `orders` — заявки и снимок источника на момент отправки;
- `referral_codes` — постоянный код пользователя и его стабильный Telegram user ID;
- `referral_attributions` — первая автоматическая привязка приглашённого клиента;
- `client_sources` — свободный ручной источник, если автоматической привязки нет.
- `admin_reply_prompts` — связь служебного сообщения администратора с заявкой.
- `conversation_messages` — постоянная связь Telegram message ID с заявкой в обе стороны;
- `pending_conversation_messages` — сообщение, ожидающее выбора заявки при нескольких открытых переписках.

В `orders.conversation_opened_at` хранится момент первого успешно доставленного ответа DES Studio. Значение `NULL` означает, что клиент ещё не может писать по этой заявке. Перезапуск бота не удаляет данные. Для базы предыдущей версии недостающие поля и таблицы добавляются автоматически.

Начальный статус заявки — `new`. Схема уже допускает значения `in_progress`, `completed` и `cancelled`, но интерфейс управления статусами в этой версии намеренно отсутствует.

```text
bot.py                 запуск и сборка приложения

utils/                  загрузка данных, форматирование, экраны
tests/                  автоматические проверки
```

## Ограничения первой версии

В проекте нет AI-консультанта, автоматического расчёта цены, оплаты, CRM, личного кабинета и веб-админки. Это соответствует границам первой версии: каталог, портфолио и заявки работают без лишней инфраструктуры.

Состояние незавершённой формы хранится в MemoryStorage aiogram: перезапуск
сбрасывает форму, но не сохранённые заявки и маршруты переписки в SQLite.
Автоматической очереди повторов уведомлений нет: при недоступном ADMIN_CHAT_ID
заявка может сохраниться без уведомления. Перед использованием проверьте
полный сценарий на собственном тестовом боте. Длинные сообщения переписки
в текущей реализации могут сокращаться.

## Настройка под свою студию

Измените каталог и демонстрационное портфолио в `data/`, приветствие в
`handlers/start.py` и упоминания DES Studio в обработчиках.
Реферальная ссылка использует username вашего бота через Telegram API.

## Данные и безопасность

SQLite содержит Telegram ID, имена, username, заявки, источники и связи сообщений.
Ограничьте доступ к базе, задайте сроки хранения и резервное копирование.
Не публикуйте базу, `.env`, ключи и журналы. `python bot.py --check` создаёт
пустую локальную базу; она исключена из Git.
MIT относится к коду и поставляемым демонстрационным материалам и не предоставляет
прав на сторонние материалы, которые вы добавите сами.
